# 알려진 한계와 미완료 항목

2026-10-23 기준.

## 실제 연동으로 확인하지 못한 것

- **Supabase 실제 프로젝트**: 계정 정보가 없어 실제 Supabase에는 연결해 보지 않았다.
  - 확인한 것: 마이그레이션 SQL과 RLS 정책은 PGlite(Postgres 17)에서 실제로 실행해 검증했다 (`tests/rls.test.ts`). Supabase의 `auth` 스키마·역할은 `supabase/tests/auth_stub.sql`로 흉내 냈다.
  - 확인할 것: 실제 Supabase에서 마이그레이션 실행, `postgres` 역할로 `set local role authenticated`가 허용되는지(Supabase 기본 구성에서는 허용되는 것으로 알려져 있음), Auth 관리자 API(계정 생성·삭제·ban) 오류 코드 처리, 세션 쿠키 갱신(proxy.ts).
- **Vercel 배포**: https://dvtarocard.vercel.app 으로 배포했다 (2026-10-23). 가입·로그인 정상 동작은 확인했고, Android·iOS 실기기와 Cron 실행은 아직 확인하지 않았다. 함수 최대 실행 시간은 플랜에 따라 다르다.
- **Claude API 실제 호출**: API 키가 없어 모의 공급자로만 테스트했다. 거절 시 대체 모델(fallbacks)은 넣지 않았고, 거절은 `AI_REFUSED` 오류로 처리된다.
- **이미지 저장**: 화면이 보이는 브라우저에서 PNG 생성(약 1.3초, 222KB)을 확인했다. 웹폰트는 포함하지 않아 저장 이미지는 기기 기본 한글 폰트로 그려진다. iOS Safari 실기기 확인은 하지 않았다.

## 화면·디자인

- 가운데 대표 캐릭터와 홈 화면 아이콘은 아직 임시 그림("행운의 별토끼")이다. `public/character/`에 이미지를 넣고 `src/config/brand.ts`에서 경로를 지정하면 모든 화면에 반영된다.
- 타일 아이콘은 기기 기본 이모지라 기기마다 모양이 다르다 (레퍼런스 같은 3D 아이콘을 원하면 이미지 에셋으로 교체 필요).

## 계산·검증의 한계

- 지원 범위: 1900–2100년, 한국 출생(Asia/Seoul)만.
- 두 로컬 엔진이 완전히 독립적이지 않을 수 있다 (`docs/ENGINE_RESEARCH.md`).
- 점봄 API는 윤달 입력을 평달로 계산하는 결함이 있어, 한·중 음력이 다른 윤달 날짜는 `UNVERIFIABLE`로 남는다. 이 분기를 확인할 실제 사례가 없어 단위 테스트가 없다.
- 점봄 API의 자시 처리는 문서가 아니라 관찰에 근거한다.
- 대운 시작 나이 12개월 이내 차이는 관법 차이로 보고 조건부 일치로 처리한다.
- 균시차는 NOAA 근사식(±0.5분 내외)이다.
- 오행 개수는 단순 글자 수 집계, 신강약·용신은 참고값. 지장간·12운성·신살·격국·합충 미제공.

## 운영상의 한계

- 사용량 기록은 AI 호출 후에 남기므로 동시 요청이 몰리면 한도를 소폭 넘을 수 있다. 제한으로 거절된 요청은 로그에 남지 않는다.
- 비밀번호 재설정 화면이 없다 (Supabase의 비밀번호 재설정 메일 기능을 붙이려면 SMTP 설정과 화면 추가 필요). 현재는 관리자가 Supabase 대시보드(Authentication → Users)에서 처리.
- 이메일 소유 확인을 하지 않는다 (가입 즉시 사용). 남의 이메일로 가입하는 것을 막으려면 확인 메일(SMTP)을 붙여야 한다.
- `SIGNUP_MODE=open`이면 주소를 아는 누구나 가입할 수 있다. 인원이 모이면 `closed`로 바꾸거나 처음부터 `invite`를 쓴다. AI 비용은 사용자별 호출 제한과 월 예산 상한으로 막는다.
- 소셜 로그인(카카오·구글 등)은 없다.
- PWA는 홈 화면 설치(manifest·아이콘)만 있고, 오프라인 캐시(서비스워커)는 아직 없다.
- 암호화 키 교체(로테이션) 도구가 없다.
- 로컬 체험 모드(PGlite)는 개발용이다. 단일 프로세스 전용이며, 개발 서버의 핫 리로드 중 드물게 내장 DB 오류가 날 수 있다 (서버 재시작으로 해결, 필요하면 `.local-db` 삭제).

## 타로·별자리

- 타로 소수 아르카나 키워드는 단순화된 조합이다.
- 별자리는 날짜 경계 근사값을 쓰고 행성 위치 계산은 없다.
